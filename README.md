# 雨宿り · Rainy Konbini

日式雨夜便利店三维微缩景观，包含逐层组装入场动画、持续降雨、水面涟漪和霓虹反光。

## 在线体验

https://liziyaaa.github.io/lizi-rainy/

拖动旋转；滚轮或双指缩放；右键拖动平移。刷新页面可重播组装动画。

## 部署

GitHub Settings → Pages → Deploy from a branch → main → /(root) → Save。

本项目是纯静态网站，无需安装依赖或构建。Three.js 和 OrbitControls 已随仓库提供。

## 本地运行

在仓库根目录启动静态 HTTP 服务即可。请使用 HTTP 访问，不要直接以 file:// 打开。
